# Cinema email delivery configuration

Cinema's sign-in, signup confirmation, and password-reset emails are sent by Supabase Auth. The application code cannot raise Supabase's project-wide email quota. Configure a custom SMTP provider in the Supabase project used by the published Lovable app.

## Brevo SMTP settings

Use the verified sender address for your Cinema domain/account and the SMTP credentials generated by Brevo.

- SMTP host: `smtp-relay.brevo.com`
- Port: `587` (STARTTLS)
- Username: the SMTP login shown in Brevo (not the API key)
- Password: the Brevo SMTP key (not the API key)
- Sender name: `Cinema`
- Sender email: the sender address verified in Brevo

Never commit SMTP credentials, paste them into frontend code, or expose them in screenshots or chat.

## Supabase setup

1. Open the Supabase project connected to Cinema.
2. Open Authentication settings and locate the SMTP settings.
3. Enable custom SMTP.
4. Enter the Brevo host, port, SMTP login, SMTP key, and verified sender details above.
5. Save the settings.
6. Review Authentication rate limits. Do not set a value higher than the SMTP provider's permitted sending rate.
7. In Authentication URL configuration, keep the published Cinema URL as the Site URL and allow the published app's password-reset and signup-confirmation redirect URLs.
8. Check the Supabase Auth logs after one controlled signup-confirmation or password-reset test. Confirm that the request is accepted by Supabase and handed to the SMTP provider.

## Verification

Test one email flow at a time:

- Signup confirmation
- Password reset
- Resend signup confirmation

Do not repeatedly submit requests while the project is still using Supabase's default email service or while SMTP credentials are invalid. A custom SMTP configuration is required to move delivery away from Supabase's restricted default sender.

This setup must be completed in the Supabase dashboard by a project owner. It cannot be completed safely from a GitHub code change because SMTP credentials are private project secrets.
